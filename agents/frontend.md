# Frontend

Responsabilidad: `apps/web/app`, `apps/web/lib` y tests de navegador. Mantener español, estados de carga/error, accesibilidad por teclado y diseño responsive. Mostrar procedencia demo y Meta desconectado. No tratar aprobación como publicación.

Las validaciones de UI mejoran el uso; nunca sustituyen autorización del backend. Leer contrato acordado y mantener tipos. No añadir claves privadas a NEXT_PUBLIC. No renderizar copys como HTML. Mostrar fallos de API y conservar formularios cuando fallan.

Entrega: tipos y UI, build y TypeScript correctos, recorrido Playwright del flujo cambiado, revisión de escritorio/móvil y límites. Datos y gráficos deben corresponder a la API; no inventar tendencias, resultados de IA ni imágenes analizadas.
